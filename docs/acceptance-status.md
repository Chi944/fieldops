## Measured evidence and remaining gates

The published [evaluation report](evaluation-report.md) identifies the exact dataset and configuration hashes for its offline run. It measures parser identifier presence, source locator presence and bounds, baseline matching and parser latency. These denominators must not be renamed field extraction accuracy, AI line detection, semantic source correctness or production reliability. The [independent gold review](../eval/gold-review.md) records its subset and the raw-evidence metadata defects that were corrected.

After the final domain release fixes, `npm test -- tests/domain-release.test.ts tests/domain.test.ts tests/domain-decisions.test.ts tests/evaluation.test.ts` passed **45 tests across four files**; ESLint passed on those changed domain paths. This targeted result is separate from the versioned parser evaluation. Final full-suite/build/browser results should be recorded by the release runner once integration is complete, without changing the meaning of earlier measurements.

The first public deployment gate is a passing production build plus browser verification of the clearly labeled fixture workflow, real originals, matrix, workbook, print view, keyboard use, narrow layout and useful failure states. Its status is **pending** here. Private-cloud release additionally needs invited and uninvited OAuth tests, cross-user source access checks, a real synthetic upload/worker/cancel/retry cycle, quota recovery and deletion on the hosted services. None are implied by embedded PostgreSQL tests.

Live AI release requires the user's configured credentials, successful development evaluation, a frozen prompt/parser/rule configuration, then a held-out run with actual field, row, matching, ambiguity, source, latency and usage denominators. Missing credentials are a precise verification blocker, not permission to use another provider or invent results. The current application is a labeled demonstration plus a real local parsing/manual-review workflow with an implemented, disabled AI adapter.

## Deferred beyond this release

DOCX, legacy XLS, handwriting and broad multilingual OCR; arbitrary merged/nested tables and reconstructed spreadsheet formulas; graduated discounts/tiers; automatic quote-level discount/tax allocation; mixed bundle allocation and milestone scheduling; automatic supplier-specific rounding policies; live FX; semantic scoring of arbitrary buyer requirements; weighted ranking; shared team administration; ERP/email integrations; automatic retention cleanup; and production-scale monitoring are follow-up work. Unsupported input must retain its original and explain the recovery path.
