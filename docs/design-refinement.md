# Workspace and review refinement

The visual direction is a quiet procurement desk: deep evergreen navigation, clear white document surfaces and a restrained paper still life. The functional comparison stays central; imagery is decorative and never substitutes for source evidence.

Tokens: evergreen `#153e38`, ink `#1c302d`, paper `#f6f7f3`, white `#ffffff`, review amber `#94601d`, action teal `#17665d`. DM Sans carries navigation and content; IBM Plex Mono is reserved for amounts. Left-aligned text, compact headings and a consistent type hierarchy replace the oversized introduction.

The workspace prioritizes resuming a real comparison, a visible review queue and direct next actions. A processing, incomplete or unapproved comparison must not be labeled ready just because it has no source issues. Search has a Ctrl/Cmd+K shortcut, a clear action and a useful empty state. Visible next-step labels remain part of their accessible names.

The welcome panel is shorter than the first release's illustration so actual comparisons appear sooner. The matrix uses neutral amounts with green reserved for eligible lowest prices, restrained amber for exclusions and issues, and a bounded scroll area that keeps supplier headers and item names visible. Print pagination retains its separate rules.

The exact image prompt, provenance and deliverable are recorded in [image assets](image-assets.md). No named image-model version is claimed because the built-in tool does not expose selection.

Review next issue opens the actual field and its available evidence without marking it resolved. On narrow screens it keeps keyboard focus visible instead of scrolling the focused field off screen to reveal the source pane. Missing citations remain explicitly missing. Matching shows unresolved groups and unmatched offers separately, with direct source links. These behaviors have a dedicated browser regression test.
